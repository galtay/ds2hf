# An Integrated TCGA Pan-Cancer Clinical Data Resource to Drive High-Quality Survival Outcome Analytics

**Liu J, Lichtenberg T, Hoadley KA, et al. Cell. 2018 Apr 5;173(2):400-416.e11**

- DOI: 10.1016/j.cell.2018.02.052
- Cell URL: <https://www.cell.com/cell/fulltext/S0092-8674(18)30229-0>
- PubMed: <https://pubmed.ncbi.nlm.nih.gov/29625055/>
- Local PDF: [`PIIS0092867418302290.pdf`](PIIS0092867418302290.pdf)

## Why this paper is in our reference list

It's the canonical curated source of TCGA clinical outcome endpoints — the
authors went back through TCGA's heterogeneous clinical data and produced
recommended definitions for the four major survival endpoints across all 33
TCGA tumor types:

- **OS** (overall survival)
- **DSS** (disease-specific survival)
- **DFI** (disease-free interval)
- **PFI** (progression-free interval)

They also flag which endpoints they consider *usable* for each tumor type
(e.g. PFI is more reliable than OS for low-mortality cancers like THCA).

## How we use it

- `ds2hf_pipeline.tcga.survival` re-derives OS/DSS/DFI/PFI from current GDC
  data using the paper's STAR Methods definitions. The results ship in the
  `survival_derived` struct/table of the TCGA patient and tabular datasets.
- Liu's own values ship verbatim, separately, in
  `gabrielaltay/tcga-pancanatlas-cdr`.
- The reproduction report below validates the first against the second.

## Relevant supplementary data

The paper ships a curated CDR (Clinical Data Resource) table — it's hosted
on the [PanCanAtlas Publications page](https://gdc.cancer.gov/about-data/publications/pancanatlas)
as `TCGA-CDR-SupplementalTableS1.xlsx`. That's the operational reference
we'd diff against; the PDF is for the methodology rationale.

## Reproduction report

Full reproduction lives in [`report.html`](report.html) (sticky TOC,
sortable tables, opens in any browser, works offline). It is assembled
from the per-section markdown files in [`sections/`](sections/), each
generated by a `section_NN_*.py` script that reads the cached cohort.

The 11 sections cover: Table 1 (cohort) and Table 2 (median follow-up)
reproductions, Liu's algorithm definitions + field rename map, per-project
survival landscape (numerical analog of Figure 1B-E), match-rate summary
against the curated CDR, per-endpoint deep-dives (OS data drift, DSS
approximations, PFI alignment, DFI's three-way OR disease-free criterion
plus the BCR biotab Clinical Supplement integration that recovered most of
DFI's lost coverage), post-2018 extension cohort, and which values to use.

See [`README.md`](README.md) for how to regenerate it.
